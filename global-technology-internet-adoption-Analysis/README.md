# 🌍 Global Technology & Internet Adoption Analysis (1990–2024)

## 📌 Project Overview

This project analyzes global technology and internet adoption trends between **1990 and 2024** using data from the **World Bank World Development Indicators (WDI)**.

The dashboard explores how internet usage and communication technologies have evolved globally, identifies leading countries in digital adoption, and highlights disparities in technology access across regions.

Developed in **Microsoft Power BI**, the project demonstrates practical skills in data cleaning, transformation, visualization, and business intelligence reporting.

---

## 🎯 Objective

The objective of this project was to examine global technology adoption trends and answer key questions such as:

- How has internet adoption changed over time?
- Which communication technology has experienced the highest adoption?
- Which countries lead in internet usage?
- How does broadband adoption compare with mobile and fixed telephone subscriptions?
- What insights can support digital transformation and policy decisions?

---

## 📊 Dataset

**Source:** World Bank – World Development Indicators (WDI)

The dataset contains development indicators for over 200 countries and territories across multiple sectors.

For this project, four technology indicators were selected:

- Individuals using the Internet (% of population)
- Mobile cellular subscriptions (per 100 people)
- Fixed broadband subscriptions (per 100 people)
- Fixed telephone subscriptions (per 100 people)

**Reporting Period:** 1990–2024

---

## 🧹 Data Cleaning & Transformation

Data preparation was carried out using **Power Query**.

The following steps were performed:

- Filtered the dataset to retain technology-related indicators.
- Removed regional aggregates and income groups.
- Unpivoted yearly columns into a long-table structure.
- Converted Year to Whole Number.
- Converted Value to Decimal Number.
- Renamed columns for clarity.
- Verified data quality.
- Retained valid zero values.
- Prepared the dataset for visualization.

## 🔍 Key Findings

- Mobile subscriptions recorded the highest level of global technology adoption.
- Internet adoption increased significantly after the early 2000s.
- High-income countries dominate internet usage rankings.
- Broadband adoption remains considerably lower than mobile subscriptions.
- Significant disparities in digital access still exist across countries.

---

## 💡 Recommendations

- Expand investment in mobile broadband infrastructure.
- Prioritize low-adoption regions to reduce the digital divide.
- Improve internet affordability and digital literacy initiatives.
