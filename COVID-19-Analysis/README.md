# 🦠 2020–2023 Global COVID-19 Analysis Dashboard

## Overview

This project analyzes global COVID-19 trends between 2020 and 2023 using Power BI.

The dashboard tracks confirmed cases, recoveries, deaths, active cases, daily growth rates, and recovery performance across countries and regions. Interactive drill-down functionality enables deeper exploration of geographic and time-based trends.

## Business Problem

During the COVID-19 pandemic, decision-makers needed a reliable way to monitor virus spread, evaluate recovery efforts, and identify emerging hotspots. However, data was often fragmented across multiple reports and difficult to interpret quickly.

This dashboard was built to answer three key questions:

* Where are cases highest?
* How fast is the virus spreading?
* How effective are recovery efforts?

## Key Learnings

This was my first healthcare dataset and my first global dataset of this scale.

Key lessons included:

* Using Unpivot to restructure data for analysis.
* Combining datasets using Append Queries.
* Understanding when to use MAX instead of SUM for cumulative metrics.
* Managing NULL values without affecting accuracy.
* Building rolling averages to identify long-term trends.
