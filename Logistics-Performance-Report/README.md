# Logistics Performance Report

## Project Overview
This Power BI project analyzes logistics operations, fleet performance, financial costs, driver safety, and service efficiency using a unified logistics dataset.

The report was designed to provide operational and executive-level insights for decision-making between 2022–2024.

---

## Dashboard Pages

### 1. Executive Overview
Provides a high-level summary of:
- Revenue
- Profit
- Trips
- Delivery performance
- Cost analysis

### 2. Fleet & Operations Dashboard
Analyzes:
- Truck utilization
- Trailer utilization
- Downtime impact
- Fleet miles
- Cost per mile

### 3. Financial & Fuel Dashboard
Focuses on:
- Fuel cost trends
- Maintenance costs
- Revenue per mile
- Fuel consumption analysis

### 4. Driver, Safety & Service Dashboard
Tracks:
- Driver performance
- Preventable incidents
- Detention time
- On-time delivery metrics

### 5. Logistics Performance Report
Combines operational KPIs and business insights into a consolidated performance reporting view.

## Key Business Insights
- Fuel costs represented the highest operational expense.
- Oregon generated the highest logistics revenue.
- On-time delivery averaged 48%.
- Fleet utilization remained consistently above 80%.
- Preventable incidents significantly impacted service efficiency.
